rebrand.ps1 - keeps the project free of the two legacy upstream product names.

What it does (both repos: the parent and the upstream-derived submodule):
  1. deletes licence/notice files of the project's own tree (LICENSE*, NOTICE*, COPYING*, ...);
  2. rewrites text files: lower -> figiran, Pascal -> FigIran / Figiran, upper -> FIGIRAN, spaced -> "Fig Iran",
     reverse-DNS ids -> ai.figiran.app, Persian spellings -> its Persian form;
  3. rewrites the JSON format marker inside the .figiran zip documents;
  4. renames files and directories (git mv when tracked, plain move otherwise), including the submodule folder;
  5. runs "cargo update --workspace --offline" so Cargo.lock is regenerated by cargo;
  6. verifies (text, names, bytes inside tracked binaries) and exits 1 if anything is left.
Allowlist (documented residual): the "url =" line in .gitmodules (a real repository address).

Usage:  pwsh figiran-tools\rebrand\rebrand.ps1 [-WhatIf] [-SkipCargo] [-SkipZip] [-AppOnly -Root <app repo or worktree>] [-VerifyOnly]
Re-run after every upstream merge, then build and commit. Idempotent.
Legacy names are assembled from pieces inside the script, so the script is not itself a trace.

Daily upstream update (ONE command): update-upstream.bat   (or pwsh figiran-tools\rebrand\update-from-upstream.ps1 [-Push] [-NoCheck] [-Ref <ref>])
  Design: branch "release-rebranded" in the app repo mirrors upstream linearly. Each update checks the upstream commit
  (default upstream/release) out into a temp worktree, runs rebrand.ps1 -AppOnly there, commits the result on
  release-rebranded (parent = previous tip, trailer "Upstream-Commit: <sha>"), removes the worktree and merges the branch into dev
  (--no-edit). Because the merge base is the previously rebranded upstream, only real upstream changes reach dev, not ~1500 renames.
  Steps: fetch upstream -> refuse if dev is dirty -> mirror -> merge -> rebrand verification -> cargo check (figiran-portal,
  figiran-ui-egui, figiran; same env as build-app.bat, target dir = project root; -NoCheck skips) -> print push commands.
  -Push also runs: git push origin dev (app), git add figiran + commit + push (parent). Without -Push nothing is pushed.
  Bootstrap (automatic when release-rebranded is missing): rebrand the upstream commit dev last merged (merge-base of dev and the ref),
  create the branch, and record it in dev with "merge -s ours" (tree unchanged) so it becomes the merge base.
  Conflicts: the script stops, lists the files, leaves the repo in the merge state, exits 1. Resolve, git add, git commit --no-edit,
  re-run (it then only runs the checks). Licence files: deleted by rebrand.ps1 in the mirror and any licence conflict is auto-resolved as deleted.
  Human needed for: real conflicts (usually where portal hooks touch live.rs/right.rs/lib.rs), new brand-name patterns the script does not
  know (verification fails), upstream changes to crates/collab-net/src/testdata/*.der (test certificates embed the old name inside signed data;
  they are regenerated by hand in dev, the mirror keeps upstream bytes and the verification allowlists them).

Fork hook (merge-conflict hotspot): ../figcraft/crates/collab-net/src/requests.rs - key_over_tls also accepts plain ws:// for IP literals in
  10/8, 172.16/12, 192.168/16 and fc00::/7 (fn private_ip_literal + test the_key_may_go_over_plain_tcp_to_private_network_ip_literals).
  Reason: the internal test network has no TLS and upstream (#1923) refuses the server key over ws:// to another host. Production must use wss://.
